| Member | Role | Responsibilities |
|---|---|---|

## Development Workflow

- Team Lead: Project coordination, GitHub administration and integration
- Backend Developer: Backend services, APIs, authentication and database
- AI/ML Developer: AI pipeline, query classification and legal retrieval
- Frontend & QA Developer: User interface, testing and documentation
