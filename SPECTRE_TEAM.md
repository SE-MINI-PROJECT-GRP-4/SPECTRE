## GitHub Responsibilities

- **Team Lead:** Organization/repository coordination, issue management, integration and release coordination.
- **Backend Developer:** Backend services, APIs, authentication and database implementation.
- **AI/ML Developer:** Query processing, legal-domain classification, AI/LLM integration and retrieval/RAG.
- **Frontend & QA Developer:** User interface, validation, testing and supporting documentation.

## Development Workflow

1. Create or select an issue.
2. Assign the issue to the responsible team member.
3. Create a feature branch.
4. Implement the assigned work.
5. Test the implementation.
6. Open a pull request.
7. Perform code review.
8. Merge the approved contribution.
